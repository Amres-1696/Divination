# 天衍 · DESTINY

一个把《周易》六十四卦做成卡牌的占卜小网站。

写下想问的事，掷六次铜钱，看本卦、变卦和爻辞。

六爻其实是六次二选一。起卦时，首页环绕的伏羲六十四卦圆图会收成 8×8 的方图（行是下卦，列是上卦），每掷一爻，不符合这一爻的那一半卦就熄灭：64、32、16、8、4、2，最后剩下的一卦就是本卦。想慢慢掷就看完，赶时间也可以直接跳过。

整个网页用 HTML、CSS 和原生 JavaScript 写成，没有后端、账号系统或数据库。不配置 AI 也能正常起卦、查看卦辞和生成分享图。

## 可以怎么玩

- **铜钱起卦**：模拟三枚铜钱，连续生成六爻，区分老阴、少阳、少阴、老阳，再算出变爻和之卦。
- **生辰起卦**：在设置里填写公历生日和时辰，程序换算农历后，结合所问的问题起卦。同一份生辰、同一个归一化后的问题，结果保持一致。
- **查看结果**：本卦、之卦、六爻之辞和主断都放在结果页。有动爻时可以点「看之卦」，动爻会在卦画上原地阴阳互变。卦序按通行本（文王序）标注。
- **每日启示**：首页每天显示一卦和一句箴言，点击能看详情，也可以在设置中关闭。
- **翻阅牌册**：在当前浏览器里保留最近 50 条记录。牌册左边是一张先天方图，抽到过的卦会亮起来，次数越多越亮，点一格只看这一卦；右边按日期分组排成时间线，支持回看、删除和清空。
- **生成分享图**：把当前结果做成图片，下载或复制；手机上也可以长按预览图保存。
- **AI 解卦**：接入自己的接口后，可以手动请求解读，或设为起卦后自动解读。最多保存 5 套接口配置，提示词也能修改。

旧版的“八字起卦”现统一显示为“生辰起卦”。当前实现是按生辰和问题取数起卦，没有完整的四柱排盘、大运、流年等功能；问题取数也是本项目的设计，不应把它当作传统命理排盘工具。

## 本地打开

下载仓库后，可以直接打开 `index.html`。如果要调试接口或图片复制，建议用本地 HTTP 服务打开，避开 `file://` 的部分浏览器限制。

电脑上有 Python 的话，在项目目录运行：

```sh
python -m http.server 8000 --bind 127.0.0.1
```

然后访问 <http://localhost:8000>。网页本身不需要安装依赖，也没有构建步骤。

放到静态网站托管服务上也一样：保留 `index.html`、`style.css`、`data.js`、`html2canvas.min.js` 和 `js/` 目录的相对位置即可。部署不需要上传本地配置或 API Key。

## AI 接口怎么填

打开右上角设置，启用“AI 解卦”，填写接口地址、API Key 和模型名称，保存后可以测试连接。

接口需要兼容 OpenAI 的 Chat Completions 格式。程序会在填写的地址后追加 `/chat/completions`，所以通常填到 `/v1` 即可，不要再把完整的 `/chat/completions` 路径填进去。模型名称以你使用的服务为准，项目不附带模型或免费额度。

浏览器会直接请求这个地址。如果遇到跨域错误，需要接口服务允许当前网站跨域访问，或者使用自己信任的代理；反复更换模型名称不会解决跨域问题。复制图片还取决于浏览器是否支持剪贴板图片写入，以及当前页面的安全上下文。

AI 解读会带上所问的问题、卦象、变爻、主断，以及记录中的起卦时间和方式。旧记录没有保存起卦方式的，会标记为未知，不会用当前设置补猜。解读可随记录保存在牌册里。

## 数据存在哪里

生辰、设置、接口密钥和牌册使用浏览器的 `localStorage` 保存。没有云端同步；换浏览器、换设备、换网站地址，都可能看到另一份数据。清除网站数据也会清掉这些内容，重要记录请自行留存。

密钥存放在浏览器中，不代表它绝不会离开本机：请求 AI 时，密钥会作为认证信息发送给你配置的接口，问题和卦象也会一起发送。请只填写自己信任的服务地址，不要把真实密钥写进源码或提交到仓库。

标题字体（Noto Serif SC）从 Google Fonts 加载，正文字体霞鹜文楷从 jsDelivr 加载，分享图片使用仓库内的 `html2canvas`。字体网络不可用时会使用系统里的宋体、楷体，显示效果可能不同。

## 代码放在哪

| 文件 | 内容 |
| --- | --- |
| `index.html` / `style.css` | 页面结构、全部样式和动画（蓝晒图纸风格：图框分区、制图角标、爻形开关、图签） |
| `data.js` | 六十四卦、爻辞、卦象解读和箴言数据 |
| `js/core.js` / `js/lunar.js` | 起卦基础计算、卦序、农历换算和工具函数 |
| `js/glyphs.js` | 卦画（SVG 与可动画的爻条）、先天序数、铜钱 |
| `js/cosmos.js` | 六十四卦图层与补间器：首页圆图、旋入方图、筛卦、飞入结果页、飞回圆图 |
| `js/ritual.js` | 起卦仪式：圆图收方图、掷钱、逐爻筛卦 |
| `js/divination.js` | 起卦流程、主断和结果页 |
| `js/history.js` / `js/settings.js` / `js/daily.js` | 牌册（方图总览与时间线）、设置和每日启示 |
| `js/instruments.js` | 生辰输入器具（年份刻度尺、农历月历、十二时辰钟）和 AI 配置页签 |
| `js/ai.js` / `js/share.js` | AI 请求、配置档案和分享图 |
| `js/theme.js` | 首页、仪式、结果页之间的转场，起卦方式切换控件 |
| `js/main.js` | 初始化和事件绑定 |
| `tests/regressions.test.cjs` | 回归测试 |

脚本按 `index.html` 中的顺序加载，调整顺序时要注意依赖。`qq-bot/` 不属于这份网页发布内容，已加入忽略列表。

## 最近整理了什么

视觉整体重做：去掉了塔罗牌、山水贴图、粒子和金色光效，换成蓝晒图纸风格与六十四卦圆图/方图，选牌改为掷钱逐爻筛卦。从结果页回首页时，卦画会飞回圆图上的原位；从牌册打开记录时，卦画从卡片飞到结果页。卡片上的卦序以前直接用了数组下标（伏羲二进制序），现在改为通行本卦序，比如山风蛊显示为第十八卦。

补上了农历换算和历史记录 ID，修正了回看时分享图拿错问题的情况。起卦中回看历史不再打断掷钱；AI 解读按记录 ID 保存，使用当次起卦的时间和方式。切后台后的粒子重复运行、修改生辰后每日卡片不刷新、设置没存进去却提示成功的问题也做了修复。

安装 Node.js 后，可以在项目目录运行测试：

```sh
node --test tests/regressions.test.cjs
```

目前有 23 项回归测试，其中包含全部 4,096 种六爻组合的变卦与主断内部一致性检查，以及逐爻筛卦（64→1）和卦序编号的检查。测试使用模拟存储、时钟、页面元素和接口，不读取你的浏览器数据，也不会调用真实 AI 服务。它们检查程序行为，不等于已经校勘全部卦辞或验证所有农历日期。

遇到问题可以提 Issue，尽量带上操作步骤、浏览器和截图。涉及接口时记得遮住密钥。

最后，卦可以看，事情还是得自己拿主意。这个项目按占卜游戏来做，不保证预测结果。
