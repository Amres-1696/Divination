# 天衍 · DESTINY

一个把《周易》六十四卦做成占卜游戏的小网站。写下想问的事，掷六次铜钱，看本卦、变卦和爻辞。

在线地址：<https://amres-1696.github.io/Divination/>

六爻其实是六次二选一。首页环绕的伏羲六十四卦圆图本来就是按二进制排的，所以起卦时它不用变成别的东西：每掷一爻，圆上不符合的那一半暗下去，剩下的正好是连续的一段弧，圆图把这段弧转到正上方，用两条线夹住。半圈、四分之一圈、八分之一圈，掷完六次只剩一卦。想慢慢掷就看完，赶时间也可以直接跳过。

整个网页用 HTML、CSS 和原生 JavaScript 写成，没有后端、账号系统或数据库，也没有构建步骤。不配置 AI 也能正常起卦、查看卦辞和生成分享图。

## 可以怎么玩

- **铜钱起卦**：模拟三枚铜钱，连掷六次，区分老阴、少阳、少阴、老阳，再算出变爻和之卦。
- **起卦过程可以调**：设置里有三档。「完整」一爻一爻来；「快掷 / 加快」把同样的过程走快一些，掷钱时点一次六爻连着掷完；「直出」不看过程，直接出结果。铜钱和生辰各存各的，互不影响。
- **生辰起卦**：在设置里填写公历生日和时辰（可以直接敲数字，也可以拨年轮、月相带和时辰钟；不清楚时辰就按子时算），程序换算成农历后，结合所问的问题取数起卦。同一份生辰、同一个问题，结果保持一致；问题里的空格、标点和全半角差异不影响结果。
- **查看结果**：本卦、之卦、六爻之辞和主断都在结果页。有动爻时可以点「之卦」，动爻会在卦画上原地阴阳互变。
- **每日一卦**：首页每天显示一卦和一句箴言，点开能看详情，也可以在设置里关闭。填了生辰的话，这一卦由生辰和当天的农历日期决定；没填则每个浏览器各自随机，当天之内不变。
- **翻阅牌册**：在当前浏览器里保留最近 50 条记录。左边是一张先天方图，抽到过的卦会亮起来，次数越多越亮，点一格只看这一卦；右边按日期排成时间线，可以回看、删除和清空。
- **生成分享图**：把当前结果做成图片，下载或复制；手机上也可以长按预览图保存。
- **AI 解卦**：接入自己的接口后，可以手动请求解读，或设为起卦后自动解读。最多保存 5 套接口配置，提示词可以改。

## 卦是怎么算的

- **主断**按朱熹《易学启蒙》的变爻取辞法：无变看本卦卦辞，一爻变看该爻，二爻变以上面的动爻为主，三爻变本卦与之卦卦辞并参，四、五爻变看之卦的不变爻，六爻全变看之卦卦辞（乾、坤用「用九」「用六」）。
- **卦序**按通行本（文王序）标注，比如山风蛊是第十八卦。
- **生辰起卦**借的是梅花易数的取数方式：年取地支数，月、日取农历，加上时辰分别起上卦、下卦和动爻，所以每次只有一个动爻。把问题也折算成数加进去是本项目自己的设计。它没有四柱排盘、大运、流年，不要当作传统命理排盘工具。
- **吉、平、凶**的印章是每一卦固定的一个粗略标注，不随变爻改变。

## AI 接口怎么填

打开右上角设置，启用「AI 解卦」，填写接口地址、API Key 和模型名称，保存后可以测试连接。

接口需要兼容 OpenAI 的 Chat Completions 格式。程序会在填写的地址后面追加 `/chat/completions`，所以通常填到 `/v1` 为止。模型名称以你用的服务为准，项目不附带模型或免费额度。

浏览器会直接请求这个地址。遇到跨域错误时，需要接口服务允许当前网站跨域访问，或者走一个自己信任的代理；换模型名称解决不了跨域。

发给 AI 的内容有：所问的问题、本卦、变卦、变爻位置、主断，以及这条记录的起卦时间和方式。旧记录没存起卦方式的会标成「未知」，不会拿当前设置去补猜。解读可以随记录存进牌册。

## 数据存在哪里

生辰、设置、接口密钥和牌册都存在浏览器的 `localStorage` 里。没有云端同步：换浏览器、换设备、换网站地址，看到的都是另一份数据；清除网站数据也会把它们清掉，重要的记录请自己留存。

密钥存在浏览器里，不等于它不会离开本机：请求 AI 时，密钥会作为认证信息发给你配置的接口，问题和卦象也一起发过去。只填自己信任的服务地址，不要把真实密钥写进源码或提交到仓库。

标题用的站酷小薇裁成了只含本站用到的字，放在仓库的 `fonts/` 里，不依赖外网。正文用的思源宋体从 Google Fonts 异步加载，连不上时用系统自带的宋体，不影响使用，只是样子会有些不同。除此之外页面不请求任何第三方资源，分享图用的 `html2canvas` 也放在仓库里。

## 本地打开和部署

下载仓库后直接打开 `index.html` 就能用。要调试 AI 接口或图片复制的话，建议用本地 HTTP 服务打开，避开浏览器对 `file://` 的限制。有 Python 的话，在项目目录运行：

```sh
python -m http.server 8000 --bind 127.0.0.1
```

然后访问 <http://localhost:8000>。

部署到任何静态托管都一样：保持 `index.html`、`style.css`、`data.js`、`html2canvas.min.js` 和 `js/`、`fonts/` 目录的相对位置即可。

`index.html` 里每个脚本和样式的地址后面带着 `?v=` 版本号，用来让浏览器丢掉旧缓存。版本号是文件内容的哈希，改完代码运行 `python tools/stamp-versions.py` 自动更新，不用手改；忘了运行的话回归测试会提醒。

改了卦名、卦辞、爻辞或界面文字，出现了以前没有的字，要重新裁一次标题字体，否则新字会退回宋体（回归测试会提醒）。先下载[站酷小薇原字体](https://github.com/google/fonts/tree/main/ofl/zcoolxiaowei)，然后：

```sh
pip install fonttools brotli
python tools/subset-font.py /path/to/ZCOOLXiaoWei-Regular.ttf
```

裁完运行一次 `python tools/stamp-versions.py` 更新版本号。

## 代码放在哪

| 文件 | 内容 |
| --- | --- |
| `index.html` / `style.css` | 页面结构、全部样式和动画（蓝晒图纸风格） |
| `data.js` | 六十四卦、爻辞、卦象解读、吉凶标注和箴言 |
| `js/core.js` | 铜钱起卦、变卦计算、卦序、提示框和小工具 |
| `js/lunar.js` | 公历转农历（1900–2100）、干支纪年 |
| `js/glyphs.js` | 卦画（SVG 与可动画的爻条）、先天序数、铜钱 |
| `js/cosmos.js` | 六十四卦图层：首页圆图、起卦时的刻度盘（转动、标线、逐爻去半）、飞入结果页、飞回圆图。动画全部交给浏览器合成线程（Web Animations），主线程忙时也不掉帧 |
| `js/ritual.js` | 起卦仪式：掷钱、逐爻揭出卦象 |
| `js/divination.js` | 起卦流程、生辰起卦、主断和结果页 |
| `js/daily.js` | 每日一卦和箴言 |
| `js/history.js` / `js/settings.js` | 牌册（方图总览与时间线）、设置 |
| `js/instruments.js` | 生辰输入（年份刻度尺、农历月历、十二时辰钟）和 AI 配置页签 |
| `js/ai.js` / `js/share.js` | AI 请求与配置档案、分享图 |
| `js/theme.js` | 首页、仪式、结果页之间的转场 |
| `js/main.js` | 初始化和事件绑定 |
| `fonts/` | 站酷小薇子集（SIL OFL 授权，附 `OFL.txt`）和它包含的字表 |
| `tools/subset-font.py` | 重新生成字体子集的脚本 |
| `tools/stamp-versions.py` | 按文件内容更新 `?v=` 版本号 |
| `tests/regressions.test.cjs` | 回归测试 |

脚本之间没有模块系统，靠 `index.html` 里的加载顺序决定依赖，调整顺序时要留意。

## 测试

装了 Node.js 就能跑，不需要安装依赖：

```sh
node --test tests/regressions.test.cjs
```

目前有 45 项回归测试，覆盖全部 4,096 种六爻组合的变卦与主断一致性、圆图上逐爻去半（64→1，每次剩下的都是连续一段弧）、卦序编号、每日一卦的分布、标题字体子集是否缺字，牌册重绘缓存，以及设置、牌册、AI 请求的各种失败情况。测试用的是模拟的存储、时钟、页面元素和接口，不读你的浏览器数据，也不会调用真实的 AI 服务。

卦辞、爻辞用的是通行本原文并加了标点，测试会检查每卦六爻齐全、爻题的九六和卦画一致；文字本身是对照通行本整理的，测试查不出个别字句的出入。每一个农历日期也没有逐日验证过。

## 反馈

遇到问题可以提 Issue，尽量带上操作步骤、浏览器和截图。涉及接口时记得遮住密钥。

卦可以看，事情还是得自己拿主意。这个项目按占卜游戏来做，不保证预测结果。
